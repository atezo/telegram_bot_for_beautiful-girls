# Проверка версии CalDAV / отдельные боты

Проверено локально 23 сентября 2026:

- 29 тестов: правила бронирования, конкурирующие заявки, перерывы, отмены, переносы,
  срок решения, повторные попытки, конфиг/env и автоматическое определение мастера.
- Реальная CalDAV-интеграция через временный Radicale 3.8.0 на localhost: создание,
  повтор операции без дубликатов, перенос, удаление встречи, восстановление перерыва,
  повторяющиеся рабочие часы с исключениями и разными окнами в конкретный день.
- Docker Compose: один проект с двумя сервисами ботов, отдельными конфигами и томами;
  конфигурация успешно разобрана, включая профиль второго мастера.

Границы проверки:

- Docker daemon в окружении не запущен: образ и контейнеры не запускались.
- Настоящий Яндекс CalDAV и Telegram не проверены с пользовательскими реквизитами.
  Проверка Radicale подтверждает работу протокола, но не гарантирует всех особенностей Яндекса.
- Требуется ручная проверка с настоящими аккаунтами: Start мастера → рабочие часы в
  Яндексе → услуга → заявка клиента → подтверждение → перенос → удаление в календаре.
- Схема существующей Google-версии и её события автоматически не мигрируют. У этой версии
  новые конфиги и отдельные тома для каждого мастера.
